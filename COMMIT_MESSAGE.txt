Fix: Resolve font path errors and add cross-platform font support

## Problem
Report generator crashed with "[Errno 2] No such file or directory" 
when trying to load DejaVu fonts from hard-coded Windows paths.

## Root Causes
1. Hard-coded absolute Windows paths (C:\Users\...)
2. Missing font validation before registration
3. No fallback mechanism for missing fonts
4. Indentation errors in report_generator.py
5. Fonts stored directly in Back_end without structure

## Solution
### 1. Path Management
- Moved fonts to `Back_end/assets/fonts/` structure
- Updated paths.py with ASSETS_DIR and proper FONTS_DIR
- All paths now use pathlib.Path for cross-platform support

### 2. Font Validation & Fallback
- Created helpers_fonts.py with validation utilities
- Added ensure_fonts_exist() for preflight checks
- Implemented automatic fallback to Helvetica
- Override set_font() for transparent fallback

### 3. Code Fixes
- Fixed 5 indentation errors in report_generator.py
  * Lines 517-524: basic_information()
  * Lines 891-895: Valuation details  
  * Lines 968-996: Image insertion blocks (3 locations)

### 4. Developer Experience
- Auto-download script: download_fonts.py
- Verification script: test_font_setup.py
- Comprehensive documentation: FONT_SETUP.md
